| 4. Calculations | Cycle opening & closing | Each cycle starts with opening rows (is_opening=true), one per account+envelope with a non-zero balance (replaces the sheet's manual '[Last Cycle] ...' rows). 'Close cycle' asks for the next pay date (pre-filled with the 25th of next month, editable), computes closing balances, locks the cycle, creates the next cycle, copies plan items and inserts opening rows. A transaction dated after the open cycle's end prompts to start the next cycle. |
| 4. Calculations | Account balance | balance(acct) = opening + Σ income where dest=acct + Σ transfer where dest=acct and source≠acct − Σ expense where source=acct − Σ saving where source=acct − Σ transfer where source=acct and dest≠acct. Saving destinations are ignored. External has no balance. |
| 4. Calculations | Total & usable funds | Total funds = Σ balances of all non-external accounts. Usable funds = Σ over accounts where counts_as_usable = true of (balance − min_balance). Both flags are set per account in Settings; the dashboard shows which accounts are included. |
| 4. Calculations | Running balance | Per transaction in date order: income adds total, transfer leaves it unchanged, expense/saving subtract total. Same rule for the plan's 'Expected Funds'; the plan's final value is the projected Remainder. |
| 4. Calculations | Reconciliation | difference = counted_balance − computed balance, per account and in total (and for usable accounts only). Highlight non-zero differences; allow a one-click 'adjustment' transaction to fix them. |
| 4. Calculations | Envelope balance | planned = Σ plan_items (expense+saving) with source envelope = env. allocated_in = opening + Σ income/transfer with dest envelope = env. spent = Σ expense+saving with source envelope = env. moved_out = Σ transfer with source envelope = env and dest envelope ≠ env. remaining = allocated_in − spent − moved_out. Show planned, allocated, spent, remaining, % used, over-budget flag. |
| 4. Calculations | Needs vs Wants | For each classification and category (expense+saving only, using the Section 2b taxonomy, plus 'Uncategorised'): money spent = Σ total; times = count; weeks = cycle_days / 7; avg times per week = times / weeks; avg per spend = spent / times (0 if no rows); spent per week = spent / weeks. Totals row per classification. |
| 4. Calculations | Subcategory analysis | Expense totals and counts per category and drill down per subcategory; optional filter by tag. |
| 4. Calculations | Plan vs actual | Per plan item (via plan_item_id) and per envelope: planned vs actual total and variance. |
| 4. Calculations | Borrows | Net balance per person = Σ amount of unsettled rows; mark settled when net = 0. |
